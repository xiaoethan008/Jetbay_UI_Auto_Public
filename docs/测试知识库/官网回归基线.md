# 官网回归基线

本文件记录每次官网版本回归时优先检查的长期基线。具体执行范围可按需求裁剪，但涉及同类功能改动时，应优先回看这些场景。

## 公共页面能力

| 场景 | 预期 | 关联资产 |
| --- | --- | --- |
| Header / Footer | 桌面和移动端可见、入口可点击、站内链接可访问 | `tests/test_home_top_navigation.py`、`tests/test_home_footer_links.py` |
| Contact Us | 关键页面弹窗可打开，联系方式完整，不展示废弃手机号 | `TC-042`、`TC-043`、`tests/test_contact_us_modal.py` |
| 移动端导航 | 汉堡菜单展开后展示核心入口 | `TC-041`、`tests/test_home_mobile_navigation.py` |
| 图片和链接 | 图片加载成功，站内链接不返回 404 或错误页 | 页面菜单类自动化 |
| 错误页识别 | 正常页面不误判，错误页摘要包含定位信息 | `TC-047` 到 `TC-050` |

## 表单提交

| 场景 | 预期 | 关联资产 |
| --- | --- | --- |
| 必填为空 | 不允许提交，错误提示明确且不遮挡后续操作 | `参考资料/测试Checklist.md` |
| 邮箱/手机号格式错误 | 不允许提交，展示格式错误提示 | `参考资料/测试Checklist.md` |
| 协议未勾选 | 不允许提交，展示协议确认提示 | `参考资料/测试Checklist.md` |
| 登录过期后提交 | 必须提示重新登录或刷新为未登录态，不得进入成功页 | `TC-057`、`tests/test_login_expired_form_submit.py` |
| 提交错误态布局 | 错误提示出现后，提交按钮和协议区仍可见、可操作 | `参考资料/漏测复盘与Bug模式库.md` |
| 防重复提交 | 连续点击提交不应产生重复订单或重复成功提示 | 待按模块补自动化 |

## 数据模块

| 场景 | 预期 | 关联资产 |
| --- | --- | --- |
| 地区切换 | 切换国家/语言/币种后，模块数据同步刷新 | `TC-056`、`TC-060`、`TC-061` |
| Excel 数据对比 | 航线、机型、Alt、富文本样式与原始数据一致 | `scripts/compare_world_cup_routes_excel.py`、`scripts/validate_popular_aircraft_by_locale.py` |
| DB 数据对比 | 页面推荐数据与数据库配置一致 | `scripts/compare_popular_aircraft_with_db.py` |
| 图片地址对比 | Next.js `_next/image?url=...` 必须先解码真实资源地址 | `参考资料/漏测复盘与Bug模式库.md` |
| 无数据状态 | 不展示旧数据或空白模块，应有合理兜底 | `参考资料/测试Checklist.md` |

## SEO

| 场景 | 预期 | 关联资产 |
| --- | --- | --- |
| Meta | Title、Description、Keywords 与需求一致 | SEO 专项脚本和问题清单 |
| hreflang | code、href、互链关系符合文档 | `scripts/seo_canonical_hreflang_scan.py` |
| robots | index/noindex 配置符合页面类型 | `scripts/seo_canonical_hreflang_scan.py` |
| 301 redirect | 废弃 URL 只发生一次 301，目标页 200 | `scripts/seo_canonical_hreflang_scan.py` |
| sitemap | 已废弃 URL 不应继续出现在 sitemap | SEO 专项脚本 |
| canonical | dev 环境当前未配置，不作为缺陷 | `环境与误报规则.md` |
| 404 | 真实 HTTP 404，不展示首页搜索模块，不跳错域名 | `TC-045`、`TC-046` |
| 富文本 Heading | News、Destination、Airports、Blogs 详情页字号/行高符合标准 | `TC-059`、`scripts/check_content_heading_styles.py` |
