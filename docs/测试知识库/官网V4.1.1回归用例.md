## 使用规则

- 本文件只记录适合纳入常规回归的稳定用例；一次性探测脚本、外部 Excel 精确比对、Marketing 依赖项不写入固定自动化矩阵。
- Empty Leg Recommendation 已迁移，旧正向页用例改为“入口隐藏 + 旧 URL 落到 Empty Leg 页面”校验。
- 对用户可见 UI / 浏览器渲染 DOM / HTTP Header 已确认通过，而仅原始 SSR HTML 残留的 SEO 差异，不作为默认全量回归阻断项。
- 已确认忽略：`Contact Our Conciergeus` 文案、首页不可见社媒图标 alt 大写 `JETBAY`。
- 本版本新增 `TC-086` 到 `TC-092`；其中 `TC-087`、`TC-088`、`TC-092` 已沉淀固定自动化，同时改造历史用例 `TC-016`、`TC-037`。

## 不纳入固定回归

| 场景 | 原因 | 建议处理 |
| --- | --- | --- |
| TC-086 Global Metadata 与 `Global翻译 (1).xlsx` 逐项精确比对 | 依赖外部 Excel，文案会随 SEO 表更新；适合版本专项，不适合默认全量自动化 | 版本 SEO 专项执行 |
| Popular Empty Leg Routes 中文/繁中标题是否展示英文城市名 | 仅能证明 Excel A 列与页面/API route title 不一致，缺少明确验收口径 | 产品确认 A 列是否为卡片标题字段后再决定是否入库 |
| TC-090 Live Empty Leg Deals 区域 tab 与排序强断言 | 列表数据、区域数量、币种和空价样本会随接口变化；当前不宜做强固定断言 | 先作为版本专项/API 探测，口径稳定后再自动化 |
| TC-091 Empty Leg 订阅提交和邮件闭环 | 提交可在 dev 执行，但后续 T3/邮件投递依赖收件箱或后台记录；不宜只做半截自动化 | 邮件专项/后台联调 |
| Empty Leg Recommendation 旧 URL SEO 404/noindex 口径 | 需求已变更为旧 URL 迁移到 Empty Leg 页面，返回 200/index 口径不再作为缺陷 | 按迁移口径回归 |
| `Contact Our Conciergeus` | 产品确认该文案符合预期 | 忽略 |
| 首页不可见社媒图标 alt 大写 `JETBAY` | 用户可见 UI 未复现；仅不可见/屏幕外 DOM alt | 忽略，除非后续明确 alt 全量替换范围 |
| Empty Leg T3 周期邮件、提交后 2 封邮件 | 需要跨天定时任务、收件箱或后台投递记录 | 邮件专项/后台联调 |
