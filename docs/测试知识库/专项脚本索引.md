# 专项脚本索引

本文件维护不进入固定 pytest 全量回归矩阵的脚本。它们可以按版本、数据源或专项任务单独执行，但不默认作为发布门禁的一部分。

## 归属规则

- `tests/` 中默认全量回归会收集的 pytest 用例，维护在 `自动化用例追溯矩阵.md`。
- SEO 专项、数据对比、Excel/DB 校验、一次性探测、报告增强脚本，维护在本文件。
- 一次性脚本不写入固定回归清单；只有用户确认长期复用后，才升级到固定回归矩阵。
- 运行产物归档到对应版本 `artifacts/官网Vx.x.x（模块名）/临时文件/`，无法确认归属时先放 `artifacts/临时文件/`。

## 本地一次性脚本处理规则

本地可能存在未提交的一次性 probe，例如 SOS 复测探测脚本。处理原则：

- 不进入固定回归矩阵。
- 不提交到 git，除非用户明确要求升级为长期脚本。
- 若保留本地文件，应在版本测试结束后归档输出产物，脚本本体按需删除或移入明确的专项目录。
