# 环境与误报规则

本文件用于防止跨环境、文档提取、视觉判断带来的误报。

## 环境规则

| 环境/场景 | 规则 |
| --- | --- |
| dev 环境 | dev 环境允许提交测试数据。 |
| dev/test SEO 自动化 | `dev`、`test` 环境默认不收集 SEO 专项 pytest 用例，也不作为全量回归的一部分；SEO 专项只在明确指定的 SEO 测试范围或具备配置的环境执行。 |
| dev canonical | dev 当前未配置 canonical，SEO 扫描不把 canonical 缺失作为缺陷。 |
| 404 SEO head/canonical | 相关参数化用例当前因需求变更跳过，不能作为失败问题上报。 |
| CDN 缓存 | SEO 变更验证需要多次请求，并记录 `x-nextjs-cache`、`etag`、实例 ID 等头信息。 |
| 业务代码仓库 | `jetbay-fe-web`、`jetbay-java-web` 只读查看，不向业务代码远端 push。详见 `参考资料/代码仓库访问规则.md`。 |
| 版本开测前代码分析 | 每个版本测试前，先同步业务代码仓库 dev 分支，分析前端/后端改动点，再决定回归范围和探索性测试重点。 |

## 新增脚本归属规则

| 场景 | 规则 |
| --- | --- |
| 新增测试脚本 | 创建或登记新脚本前，先向用户确认它是“固定回归脚本”还是“一次性专项脚本”。 |
| 一次性专项脚本 | 不写入固定回归用例清单，不纳入全量回归和质量门禁；执行产物归档到版本目录或 `artifacts/临时文件`。 |
| 固定回归脚本 | 只有用户确认需要长期复用后，才登记到 `artifacts/测试用例清单.csv`、版本追溯矩阵和全量回归命令。 |
| 历史 Alt 脚本 | 图片 Alt Excel 对比脚本已标记为一次性专项；仅在用户明确要求 SEO Alt 专项时单独执行。 |

## 版本开测前代码分析规则

| 步骤 | 规则 |
| --- | --- |
| 同步前检查 | 在业务代码仓库内先执行 `git status --short`，确认是否有本地未提交改动；如有改动，先暂停并说明，避免覆盖他人工作。 |
| 同步分支 | 确认仓库在 dev 分支或切到 dev 分支后，再执行只读同步，例如 `git fetch`、`git pull --ff-only`。 |
| 改动分析 | 对比上次测试基线或最近一次记录，查看 `git log`、`git diff --stat`、关键文件 diff，梳理改动页面、组件、接口、SEO、表单和数据模块。 |
| 风险映射 | 把改动点映射到 `官网回归基线.md`、`历史问题与复测点.md` 和 `artifacts/测试用例清单.csv`，确定必跑用例、专项脚本和探索性测试点。 |
| 结果归档 | 在当前版本目录记录 `代码改动分析.md`，内容包括同步时间、仓库分支、commit 范围、改动模块、风险点、建议测试范围。 |
| 禁止事项 | 业务代码仓库只读分析，不向业务远端 push，不提交业务代码修复，不删除或重置业务仓库本地改动。 |

## 文档识别规则

| 场景 | 规则 |
| --- | --- |
| 删除线 | 需求文档中带删除线的内容视为已删除需求，不作为测试期望。 |
| 多次上传文档 | 以用户明确指定的最新文档为准；旧文档只作为历史参考。 |
| 文档截图 | 截图只能辅助理解，最终需结合文本、页面实际和用户确认。 |
| `%currentyear%` | SEO 需求中的 `%currentyear%` 应按当前年份替换，例如 2026。 |

## UI / 视觉误报规则

| 场景 | 规则 |
| --- | --- |
| DOM 与可见 UI 不一致 | 不能只靠 DOM 文本判断，必须结合截图、可见区域、computed style。 |
| 装饰性符号 | 标题后的装饰点、伪元素、背景图文字，不直接当作正文缺失或多余。 |
| 图片地址 | Next.js `_next/image?url=...` 对比前必须解码真实资源地址。 |
| 相似实体 | 相似但不同的实体必须区分，例如 `Gulfstream G650` 与 `Gulfstream G650ER`。 |
| Hover / 下拉 | 需要截图确认浮层、选项和 hover 状态，不只检查元素存在。 |
| 动态容器 | 对动态增高表单，必须检查关键按钮实际可见比例。 |

## 数据对比规则

| 场景 | 规则 |
| --- | --- |
| 地区切换 | 依赖地区/语言/币种的模块，不能只测默认地区，必须逐项切换。 |
| Excel 对比 | 先确认 Excel 字段含义，不确定字段不要擅自命名。 |
| DB 对比 | 图片字段比较要解码页面真实资源地址，并按准确 aircraft_id / aircraft_name 匹配。 |
| 无数据模块 | 页面无数据时不能展示旧数据；如果需求允许空态，应有明确兜底。 |
