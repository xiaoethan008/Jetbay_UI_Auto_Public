# JETBAY 官网测试 Checklist

本文件用于回归、需求测试和探索性测试前快速过一遍风险点。不同模块不必全部执行，按需求范围和风险选择。

## 通用页面

- 页面可正常打开，HTTP 状态和最终 URL 符合预期。
- 桌面和移动端首屏无明显遮挡、重叠、错位、横向滚动异常。
- Header、Footer、Logo、菜单、Contact Us 等公共组件可用。
- 页面主 CTA 可见、可点击，点击后跳转或打开弹窗符合预期。
- 图片加载成功，关键图片不空白、不变形，Alt 文案符合需求或 SEO 数据。
- 站内链接可访问，不跳到错误域名或 404。
- 异步加载模块有数据时展示数据，无数据时有合理兜底。
- 多语言/多地区页面文案、币种、地区选择状态一致。

## 表单

- 必填字段为空时提示明确，错误提示位置不遮挡后续操作。
- 输入非法字符、超长文本、空格、重复值时有校验。
- 城市/机场搜索必须选择有效下拉项，不能仅输入自由文本后通过。
- 日期选择符合业务规则，禁选日期不可提交。
- 乘客数、航段数、金额等数字控件边界值正确。
- 正常提交后进入预期成功页或展示成功反馈。
- 提交失败后按钮仍可见、可点击，表单不被弹窗或容器裁切。
- 防重复提交：连续点击提交不会产生多条异常请求。
- 登录态过期后提交必须提示重新登录或刷新为未登录态，不得进入 thankyou。
- dev 环境允许提交测试数据时，仍需检查接口返回和页面反馈。

## 弹窗 / 下拉 / Hover

- 弹窗打开后标题、内容、关闭按钮、蒙层状态正确。
- 弹窗内部可滚动时，底部按钮和协议区不被裁切。
- Escape、关闭按钮、点击蒙层的关闭行为符合预期。
- 下拉展开后选项可见，选项数量和接口/需求一致。
- 选择、取消、清空筛选后页面状态刷新。
- Hover 状态需要截图确认，不只检查 DOM。
- tooltip、伪元素、装饰点等不要误判为正文需求。

## 数据模块

- 明确数据来源：Excel、API、DB 或 CMS。
- 页面默认地区数据与数据源一致。
- 切换地区/语言/币种后数据刷新，不残留旧地区数据。
- 列表顺序、排序字段、数量限制与需求一致。
- 卡片字段逐项对比：标题、城市、机场、时间、机型、价格、描述、图片。
- 图片对比必须解码真实资源地址，例如 `/_next/image?url=...`。
- 同名或相似实体要区分，例如 `Gulfstream G650` 与 `Gulfstream G650ER`。
- 无数据时不应展示旧数据或空白模块。

## 多地区 / 多语言

- 地区选择弹窗可打开、可关闭、可确认。
- 当前地区和币种展示正确。
- 切换地区后 URL、Header 状态、页面内容同步变化。
- 多地区模块逐个切换验证，不只检查默认地区。
- 中文、英文、繁中页面文案应匹配对应版本需求。
- 页面内不要混入不该出现的语言。

## SEO

- Meta Title、Description、Keywords 与需求一致。
- 多次请求验证缓存是否已清理，记录 cache header 和 etag。
- hreflang 数量、code、href、互链关系符合文档。
- robots index/noindex 配置符合页面类型。
- Deprecated URL 的 301 跳转目标正确，避免跳转链。
- Sitemap 中 URL 可访问，已废弃 URL 不应继续出现。
- dev 未配置 canonical 时不把 canonical 缺失作为缺陷。
- 404 页面返回真实 HTTP 404，不展示首页搜索模块，不跳错域名。
- 内容详情页富文本 H1-H4 字号和行高符合桌面/移动设计标准。

## 视觉 / 布局

- 截图覆盖桌面和移动端。
- 固定 Header、侧边栏、悬浮工具不遮挡正文和按钮。
- 动态增高模块要检查容器是否裁切内容。
- 长文案、长单词、多语言文案不溢出按钮或卡片。
- 轮播至少验证首帧、切换帧、链接、移动端状态。
- 背景图、装饰图、伪元素参与视觉判断时，以截图为准。
- 不只判断元素存在，还要判断实际可见比例。

## 回归与问题清单

- 回归前先查看当前版本问题清单和历史问题。
- 已修复问题不删除，更新“是否已修复 / 复测结果 / 证据”。
- 需求删除或变更的问题，在备注中说明，不继续作为缺陷。
- 新发现 bug 要补复现步骤、预期、实际、证据截图。
- 可自动化的 bug 必须补测试用例或脚本。
- 每次漏测复盘后，补充到 `docs/测试知识库/参考资料/漏测复盘与Bug模式库.md`。
