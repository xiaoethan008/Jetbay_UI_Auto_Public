## 复测处理规则

- 已修复问题不从问题清单删除，更新“是否已修复 / 复测结果 / 证据”。
- 需求删除或变更的问题，在备注中说明，不继续作为缺陷。
- 能自动化的历史问题，补 `tests/` 或 `scripts/`，并在 `artifacts/测试用例清单.csv` 登记。
- 不能稳定自动化的问题，补 `参考资料/测试Checklist.md`，回归时人工/探索性验证。
