## 维护规则

- 本矩阵只收默认全量回归可收集的固定 pytest 用例。
- SEO 专项、数据对比、一次性探测、人工调试脚本不写入固定回归矩阵，统一维护在 `docs/测试知识库/专项脚本索引.md`。
- 新增固定回归用例时，必须补充稳定 Case ID、关联 TC、脚本函数、覆盖点和依赖说明。
- Case ID 使用 `AUTO-{模块}-{三位序号}`，同一业务模块内递增；Case ID 一经发布不随用例标题调整而变更。
- 用例若依赖登录、数据库、三方接口或特定环境配置，必须在备注中说明。
- `dev` / `test` 环境不跑 SEO 专项脚本；SEO 用例只在目标环境具备 SEO 配置时单独执行。
- 人工调试用例不得以 `test_*.py` 形式进入全量回归；当前由 `conftest.py` 忽略收集。
