# 自动化用例追溯矩阵

本文件维护“业务模块 / 自动化用例 / 页面对象方法 / 历史问题”的对应关系。它回答三个问题：

- 某个页面或模块现在由哪些自动化用例覆盖？
- 某条失败问题对应哪些脚本和页面对象方法？
- 某个脚本是固定回归用例，还是一次性/人工调试脚本？

## 维护规则

- 新增固定回归用例时，必须补充到本矩阵。
- 新增一次性脚本或专项排查脚本时，不写入固定回归矩阵，只放 `artifacts/临时文件` 或 `scripts/` 并在提交前确认是否保留。
- 修复自动化误报时，在“历史问题/备注”中记录问题 ID 和修复点。
- 用例若依赖登录、数据库、三方接口或特定环境配置，必须在备注中说明。
- `dev` / `test` 环境不跑 SEO 专项脚本；SEO 用例只在目标环境具备 SEO 配置时单独执行。
- 人工调试用例不得以 `test_*.py` 形式进入全量回归。
